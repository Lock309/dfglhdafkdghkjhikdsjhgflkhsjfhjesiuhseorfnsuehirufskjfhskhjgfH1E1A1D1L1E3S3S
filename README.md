To use this Headless In codespace because yes it is on codespace only:
Do npm install in the terminal (no download needed)
then npm start to start up the port
forward the port if isn't auto, then make the port public
after that use your controller by copy and paste the entire code in it and put it in tampermonkey or what
and now please input the localhost of the codespace to make it work on the codespace manager and then connect it
theres a watcher which watches your codespace simultaneously every 30 seconds, it scans 3 secs and then cooldown for 30s
and now u can deploy the swarm!
